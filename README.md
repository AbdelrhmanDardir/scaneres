# ماسح المستندات (DocScanner)

تطبيق أندرويد لمسح المستندات: كاميرا، قص تلقائي للحواف مع تعديل يدوي، 3 فلاتر، استخراج نص (OCR)، وحفظ PDF وWord.

## إزاي تطلّع ملف التثبيت (APK) من غير Android Studio

1. ارفع كل ملفات المشروع على GitHub (مستودع جديد).
2. GitHub هيبني التطبيق لوحده (تبويب **Actions**، حوالي 8–12 دقيقة).
3. لما يظهر علامة ✓ خضرا، افتح **Releases** من الصفحة الرئيسية للمستودع ونزّل `DocScanner.apk`.
4. افتح الملف على موبايلك وثبّته (وافق على "التثبيت من مصدر غير معروف" لو سأل).

لو البناء فشل (علامة ✗ حمرا): افتح المحاولة الفاشلة، اضغط على الخطوة اللي فيها ✗، وانسخ سطور الخطأ.

## ملاحظات

- قارئ النصوص (Google ML Kit) بيقرأ الحروف اللاتينية (إنجليزي وفرنسي وغيرها) ومش بيقرأ العربي.
- الملفات المحفوظة بتروح لمجلد `Documents/DocScanner` على الموبايل.
- أقل إصدار أندرويد: 10.
